# SomaFM voice playback

The opt-in audio module uses SomaFM's published station catalog and playlists. DEF CON Radio is the default station (`defcon`). The captured catalog contains station IDs, titles and MP3 playlist URLs from [SomaFM's catalog](https://somafm.com/channels.json), captured October 4, 2026. No arbitrary stream URL, local file, or user-provided command is accepted. Playlist responses are bounded to 64 KiB and ten endpoints; only HTTPS SomaFM ice-server MP3 URLs are accepted, without redirects, credentials, query strings or custom ports.

Set `BOT_VOICE_INTENT=true` and restart the bot to enable Guild Voice States. Enable audio for the selected server, join a voice channel and use `/radio play`. `/radio stations` lists published station IDs; `/radio status` reports actual connection/player state and processed duration. `/radio stop` requires the requester or a DJ. Configured DJ roles restrict starts; Manage Server or Manage Channels also grants DJ control. A DJ can select a destination channel explicitly. Current bot View Channel, Connect and Speak permissions are required.

The runtime uses `@discordjs/voice` 0.19.2, its installed DAVE implementation, an Opus encoder and FFmpeg. The pinned package requires Node 22.12 or newer; inspect the lockfile and runtime dependency report rather than assuming the documentation site's current runtime requirement describes the pinned package. Discord's [voice library](https://discord.js.org/docs/packages/voice/0.19.2) supports DAVE; this implementation requires a negotiated DAVE protocol before playback starts. FFmpeg decodes the approved response through stdin and emits PCM; it receives no user-controlled command arguments or network URL.

Playback has a server duration limit of 1–120 minutes and stops after a configured empty-channel interval. At most three radio sessions run in one bot runtime. A database partial unique index permits only one starting/playing record per server. Monitoring stops sessions when the module is disabled, required bot permissions are lost or the requester's configured DJ permission is revoked. Native voice recovery gets a bounded rejoin attempt. Stop aborts source reads, terminates FFmpeg, stops the player and destroys the voice connection.

Operate one bot owner per database/application. A sole-owner restart marks prior starting/playing records interrupted and requires a new authorized start; it does not replay a stream automatically. Playback metadata expires after 90 days, with a 1000-record server limit. Do not run multiple independent bot processes against the same pilot database. Startup recovery is not distributed ownership arbitration.

Live qualification on October 4 negotiated DAVE protocol 1 in server `947948179897327686`, processed approximately eight seconds of DEF CON Radio audio, continued after a requested voice rejoin and stopped cleanly. The private fixture channel and source processes were removed. This proves connection, processing, rejoin and stop behavior. It does not prove human audible output, a real network outage, sustained operation, queues, playlists, clips, or permission to advertise a public radio relay. Public provider/source usage and the remaining A02/A03 gates must be reviewed before release claims.
